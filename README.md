# sistema_peaje

A new Flutter project.

**Para ejecutar el proyecto Flutter, sigue estos pasos:**

1. **Instala Flutter**: Asegúrate de tener Flutter instalado en tu sistema. Si no lo tienes, sigue las instrucciones en [flutter.dev](https://flutter.dev/docs/get-started/install).

2. **Instala dependencias**: Abre una terminal en la raíz del proyecto (donde está el archivo pubspec.yaml) y ejecuta:
   ```sh
   flutter pub get
   ```

3. **Selecciona un dispositivo**:
   - Si estás en un entorno de desarrollo con un emulador (Android Emulator), asegúrate de que esté ejecutándose.
   - Si tienes un dispositivo físico, conéctalo a tu computadora y habilita la depuración USB.

4. **Ejecuta el proyecto**:
   En la terminal, ejecuta:
   ```sh
   flutter run
   ```
   Esto compilará y ejecutará el proyecto en el dispositivo/emulador conectado.

5. **Especificar plataforma (opcional)**:
   Si deseas ejecutar en una plataforma específica, puedes usar:
   - Android: `flutter run -d android`
   - iOS: `flutter run -d ios`
   - Web: `flutter run -d web`
   - Windows: `flutter run -d windows`
   - Linux: `flutter run -d linux`
   - macOS: `flutter run -d macos`

6. **Depuración en Visual Studio Code**:
   - Abre el proyecto en Visual Studio Code.
   - Instala la extensión de Flutter si no lo has hecho.
   - Presiona `F5` o selecciona "Run and Debug" para iniciar el proyecto.

Si encuentras algún error, verifica que las dependencias estén correctamente configuradas en el archivo pubspec.yaml y que el SDK de Flutter esté actualizado.
